PATARTIST PHP VERSION

1. Положи папку проекта в htdocs (XAMPP), например:
   C:\xampp\htdocs\patartist_php

2. Скопируй свои существующие style.css и папку img в проект.
   В img/portfolio/ положи свои работы с именами:
   work1.jpg, work2.jpg, work3.jpg, work4.jpg, work5.jpg, work6.jpg

3. Запусти Apache и MySQL в XAMPP.

4. Открой phpMyAdmin и импортируй database.sql.

5. Открой:
   http://localhost/patartist_php/index.php

PHP-функции:
- портфолио с ячейками для картинок;
- поиск по работам;
- форма контактов;
- сохранение результатов Сапёра в MySQL;
- таблица рекордов.
